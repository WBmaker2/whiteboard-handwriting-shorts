# Changelog

All notable changes to this project are documented in this file.

## [1.0.1.0] - 2026-08-21

### Added

- Operating-system-specific Python, Git, FFmpeg and FFprobe setup guidance.
- Google AI Studio Gemini API key issuance, environment-variable registration and value-free status checks.
- Read-only environment preflight with an explicit Python 3.10 minimum-version guard.
- Approval-gated Python package planning, application and installation retry guidance.
- Offline tests for environment checks and secret-value non-disclosure.

## [1.0.0.0] - 2026-08-21

### Added

- Initial public release of the `whiteboard-handwriting-shorts` Codex skill.
- Six approval-gated stages for educational Shorts production.
- One-time approved runtime bootstrap using only the two documented official GitHub repositories.
- Explicit upstream or no-text drawing-hand selection and provenance recording.
- Gemini TTS, subtitle, whiteboard rendering and vertical video assembly helpers.
- Per-video project folders with approval and source records.
- Distribution validation, offline bootstrap integration tests and GitHub Actions.
