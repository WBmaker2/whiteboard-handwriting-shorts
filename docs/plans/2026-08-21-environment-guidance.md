# 실행 환경 안내 및 사전 점검 구현 계획

## 목적

스킬을 처음 받은 사용자가 운영체제별 필수 도구를 준비하고 Gemini TTS를 사용할 수 있도록 안내합니다. 실제 영상 제작 전에 Python 버전, Git, FFmpeg, FFprobe, 스킬 전용 Python 패키지, Gemini API 키의 상태를 안전하게 확인하도록 합니다.

## 구현 범위

1. `scripts/check_environment.py`를 추가해 Python 3.10 이상과 시스템 명령, Gemini 키 존재 여부를 점검합니다.
2. `scripts/prepare_env.py`에 `--check`, `--plan`, `--apply --approved` 흐름을 추가합니다. 패키지는 사용자 승인 후에만 설치합니다.
3. `scripts/bootstrap_runtime.py`와 Gemini TTS 진입점에서 Python 최소 버전을 실제 실행 전에 확인합니다.
4. macOS·Windows 설치 방법, Linux 환경변수 명령, Gemini API 키 발급 및 안전한 확인 방법, 설치 실패 재시도 절차를 문서화합니다.
5. CI와 로컬 회귀 테스트에 사전 점검·키 비노출·패키지 계획 동작을 추가합니다.
6. 변경 사항을 버전·변경 기록에 반영하고 GitHub 커밋, 푸시, CI와 릴리스까지 확인합니다.

## 안전 원칙

- Python·Git·FFmpeg·FFprobe 같은 시스템 도구는 자동 설치하지 않고, 공식 배포처와 사용자가 실행할 명령을 안내합니다.
- `google-genai` 등 Python 패키지는 계획을 먼저 출력하고 사용자가 승인한 경우에만 스킬 전용 `.venv`에 설치합니다.
- API 키 값은 출력·기록·커밋하지 않습니다. 점검 결과는 `present` 또는 `not-set`만 표시합니다.
- 설치 실패 시 기존 `.venv`와 저장소를 삭제하거나 초기화하지 않고, 원인을 해결한 뒤 같은 점검·계획·승인 적용 순서로 재시도합니다.
- 최초 실행용 저장소 준비와 영상별 제작 승인 게이트는 기존 스킬의 절차를 유지합니다.

## 검증 기준

- Python 3.9 이하로 진입하면 명확한 업그레이드 안내와 함께 중단됩니다.
- 필수 명령이 없으면 플랫폼별 설치 문서 위치를 안내하고 영상 제작을 시작하지 않습니다.
- 키가 설정된 테스트에서도 실제 키 문자열이 출력에 포함되지 않습니다.
- 승인 플래그 없이 `--apply`를 실행하면 설치하지 않고 중단됩니다.
- CI에서 API 키 없이도 비밀값 비노출·환경 점검 테스트가 통과합니다.
